🚀 AI Resume Analyzer & Job Match System

An AI-powered web application that analyzes your resume against a job description, identifies matching and missing skills, and generates a downloadable PDF report.

🌐 Live Demo

👉 Try AI Resume Analyzer

✨ Features

* 📄 Upload and analyze your resume
* 🎯 Compare your resume with a job description
* ✅ Identify matched skills and missing skills
* 📊 Get a resume-job match score
* 💡 Receive suggestions to improve your resume
* 📥 Download a detailed PDF analysis report
* 🎨 Clean, modern, and responsive user interface

🛠️ Technologies Used

* Python
* Streamlit
* PDF Processing
* Resume Parsing
* Skills Matching
* ReportLab for PDF Report Generation

💻 Run Locally

1. Clone the repository

git clone https://github.com/harshittripathi1404-gif/AI-RESUME-ANALYZER.git

2. Open the project folder

cd AI-RESUME-ANALYZER

3. Install dependencies

pip install -r requirements.txt

4. Run the application

streamlit run app.py

🎯 Project Objective

The goal of this project is to help job seekers understand how well their resumes match job descriptions, identify skill gaps, and improve their chances of getting shortlisted.
